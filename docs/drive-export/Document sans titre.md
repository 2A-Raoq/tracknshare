# Documentation Projet Gaming Platform

## Structure du Drive

Ce drive contient toute la documentation du projet fil rouge.

### Organisation

- Dossiers numérotés par ordre logique de consultation

- Chaque dossier contient des documents spécifiques à son domaine

- Les diagrammes sont en PDF pour une meilleure compatibilité

- Les documents modifiables sont en .docx ou .xlsx

### Conventions

- Tous les noms de fichiers en français

- Pas d'espaces dans les noms (utiliser des tirets)

- Dates au format YYYY-MM-DD si nécessaire
