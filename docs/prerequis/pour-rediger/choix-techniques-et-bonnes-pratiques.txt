========================================================================
TRACK'N SHARE — CHOIX TECHNIQUES & BONNES PRATIQUES (synthèse)
========================================================================

ARCHITECTURE
- Monorepo pnpm workspace + Turborepo : 3 apps (api, web, mobile),
  dépendances partagées, builds incrémentaux, une seule CI.
- Package de types partagés (packages/shared-types) consommé par web et
  mobile : le contrat API est typé à un seul endroit, zéro divergence.

BACK-END (apps/api) — NestJS 11 + TypeScript
- Architecture modulaire (1 module par domaine), controllers fins,
  logique dans les services, validation par DTO (class-validator).
- Auth JWT/Passport + bcrypt, routes protégées par guards.
- PostgreSQL via TypeORM (+ migrations), API documentée avec Swagger.
- Providers externes isolés côté back (MockProvider) : aucun secret client.

FRONT WEB (apps/web) — React 18 + Vite + PWA
- Installable (service worker), responsive mobile-first, thème gaming.
- Formulaires validés par schémas zod (miroir des DTO serveur), état valtio,
  appels API centralisés (axios) avec états loading/error/empty et validation
  runtime des réponses.

MOBILE (apps/mobile) — Expo / React Native
- Vraie app native qui consomme la MÊME API NestJS.
- Token en secure-store, navigation expo-router, notifications in-app
  temps réel (socket global + bannière animée).

TEMPS RÉEL — Socket.io
- Chat d'équipe, messages privés, notifications. Socket authentifié par
  JWT : messages inaccessibles aux non-membres.

PERFORMANCE
- Redis (cache, temps réel, rate limiting), index PostgreSQL,
  pagination par curseur, CacheInterceptor, throttler configurable.

SÉCURITÉ & RGPD
- Aucun secret côté client, helmet + CORS restreint, validation des entrées,
  permissions vérifiées côté serveur.
- Consentement, page de confidentialité, endpoints RGPD, données de démo
  fictives.

QUALITÉ & INDUSTRIALISATION
- Tests : Jest + Supertest (api, dont e2e), Vitest + Testing Library (web).
- CI GitHub Actions (lint + test + build) sur chaque PR.
- Docker + docker-compose (api, web, PostgreSQL, Redis) en une commande.
- ESLint + Prettier + TypeScript strict, workflow Git branches + PR.

MÉTHODE
- MVP priorisé (P0 avant bonus), doc d'architecture dans le dépôt,
  usage de l'IA (Claude Code) encadré par une politique documentée.
